# 🤖 AI-Powered Resume ATS Score Checker

An AI-powered web application that analyzes a resume against a target job description and generates an **explainable ATS compatibility score**, skill-gap analysis, keyword matching results, semantic similarity, and actionable recommendations.

> **Project Type:** Natural Language Processing / Artificial Intelligence Web Application
> **Academic Level:** B.Tech Artificial Intelligence & Data Science

---
Live Demo:
https://ai-ats-checker-three.vercel.app/

## 📌 Project Overview

The **AI Resume ATS Score Checker** helps job seekers understand how well their resume matches a particular job description.

The system accepts a resume in **PDF or DOCX format** and a target job description. It then uses NLP, keyword matching, technical skill detection, and transformer-based semantic similarity to evaluate the resume.

The application provides:

* ATS compatibility score
* Keyword match percentage
* Technical skill match
* Semantic similarity
* Resume structure analysis
* Missing keywords
* Missing technical skills
* Matched skills
* Job-specific recommendations

The project is designed as a **portfolio-ready AI/NLP application** demonstrating practical use of Natural Language Processing and machine learning.

---

## ⚠️ Important Note

The ATS score generated by this application is a **project-defined compatibility score**.

It is **not the proprietary score of any real Applicant Tracking System (ATS)**.

Different ATS platforms use different screening algorithms and configurations.

## 📊 ATS Score

The system calculates an explainable score from multiple components.

| Component              |   Weight |
| ---------------------- | -------: |
| Keyword Match          |      30% |
| Technical Skills Match |      30% |
| Semantic Similarity    |      25% |
| Resume Structure       |      15% |
| **Total**              | **100%** |

### Formula

```text
ATS Score =
0.30 × Keyword Score
+
0.30 × Skill Score
+
0.25 × Semantic Score
+
0.15 × Structure Score
```

### Score Interpretation

|    Score | Rating            |
| -------: | ----------------- |
|   85–100 | Excellent         |
|    70–84 | Good              |
|    55–69 | Needs Improvement |
| Below 55 | Poor              |

# 🔄 How It Works

## Step 1 — Upload Resume

The user uploads:

```text
Resume.pdf
```

or:

```text
Resume.docx
```

The parser automatically detects the file format.

---

## Step 2 — Enter Job Description

The user pastes a target job description.

Example:

```text
We are looking for an AI Engineer.

Requirements:

Python
Machine Learning
Deep Learning
TensorFlow
PyTorch
SQL
NLP
Computer Vision
Git
Docker

The candidate should have experience
developing machine learning models
and deploying AI applications.
```

---

## Step 3 — Extract Resume Text

For PDF:

```text
PyMuPDF
     ↓
PDF
     ↓
Extracted Text
```

For DOCX:

```text
python-docx
     ↓
DOCX
     ↓
Extracted Text
```

---

## Step 4 — NLP Preprocessing

The system performs:

* Text normalization
* Lowercase conversion
* Whitespace normalization
* Tokenization
* Lemmatization
* Removal of unnecessary characters

spaCy is used for NLP processing.

---

## Step 5 — Keyword Matching

Important keywords are extracted from the job description using TF-IDF.

The system compares those keywords with the resume.

Example:

```text
Job Description:

Python
Machine Learning
TensorFlow
SQL
NLP
Docker
```

Resume:

```text
Python
Machine Learning
SQL
NLP
```

Result:

```text
Matched:

✓ Python
✓ Machine Learning
✓ SQL
✓ NLP

Missing:

✗ TensorFlow
✗ Docker
```

# 🧠 Semantic Similarity

Keyword matching alone cannot understand meaning.

For example:

```text
Resume:

Developed predictive models using Python.
```

Job description:

```text
Experience developing machine learning models.
```

Even though the exact words are different, the meanings are related.

The project uses:

```text
Sentence Transformers
        ↓
all-MiniLM-L6-v2
        ↓
Text Embeddings
        ↓
Cosine Similarity
        ↓
Semantic Similarity Score
```

This allows the application to identify related content beyond exact keyword matching.

# 🔐 Security & Privacy

Resume files may contain sensitive personal information.

A production deployment should:

* Validate file extensions
* Validate MIME types
* Limit upload size
* Generate safe server-side filenames
* Avoid publicly exposing uploaded resumes
* Delete temporary files when appropriate
* Use HTTPS
* Never commit real resumes to GitHub

These privacy and security considerations are especially important for a resume-processing application.
